# 🛸 UFO-Sightings-PowerBI-Dashboard
This Power BI report explores global UFO sightings between 1980 and 2014. The dashboard includes analysis by shape of the UFO craft, sighting duration, geographic locations, and time trends. 

## 📌 Overview
This Power BI dashboard explores historical UFO sightings worldwide from **1980 to 2014**. Created as part of a Power BI course, the project showcases data cleaning, transformation, and visualization skills.

---

## 🎯 Objectives
- Analyze UFO sighting trends over time
- Visualize popular craft shapes
- Explore sightings by region and duration
- Build an interactive dashboard using slicers and filters

---

## 🛠 Tools Used
- **Power BI Desktop**
- **Power Query**
- **DAX**
- **Map Visuals (Bing)**
- **Slicers, filters, and conditional formatting**

---

## 📊 Key Visuals
- Area chart for sighting duration over time
- Bar chart for craft shapes
- Map visualization by country and state
- Slicers for the month and year range

---

## 📈 Insights
- Sighting frequency increased post-1995
- Common UFO shapes: *light*, *triangle*, *circle*
- Most sightings were under 10 minutes
- The U.S. had the highest number of reported sightings

---

## 🔗 How to Use
1. Download `UFO_Sightings_Dashboard.pbix`
2. Open it with Power BI Desktop
3. Interact with the slicers and visuals to explore the data
